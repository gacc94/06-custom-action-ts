# 🛡️ Security Policy

## Supported Versions
Security updates and patches are actively provided for the following versions:

| Version | Supported |
| :--- | :---: |
| 1.x | ✅ |
| < 1.0 | ❌ |

## Reporting a Vulnerability
Security is a top priority for this Custom Action. If you identify a potential security vulnerability:

1. **DO NOT** open a public issue.
2. Use GitHub's native **Private Vulnerability Reporting** via the repository's **Security** tab.
3. Provide a detailed summary, reproducible steps, and any proof-of-concept details or recommended remediations.

We will acknowledge receipt within 48 business hours and provide status updates on remediation and release.
